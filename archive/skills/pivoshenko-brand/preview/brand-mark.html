The Mark typeset, never an image file

The site's first two letters set in JetBrains Mono on an fg-default tile, with a 7px accent notch at the bottom-right. There is no logo SVG - the mark is markup, so it inherits the accent channel like everything else.

Construction
tile fg-default, radius-sm
letters bg-canvas, mono 800, -0.04em
notch 7px, --accent, radius 2px
ring 2px bg-canvas around the notch
Sizes
pv16 favicon
pv24 nav
pv32 header
pv48 cover

Below 16px the notch stops reading - drop it and keep the tile. The notch never fills the tile, and the tile is never accent-coloured.

type-logo, gap space-2. Root in fg-default, the dot in fg-faint, the namespace in --accent. The namespace is what tells sibling sites apart - the mark stays the same.
