Prose the reading layer - plain HTML, no classes inside

The reading layer

Everything inside Prose is plain HTML. Headings, paragraphs, lists, quotes, code and tables inherit the system without a single class, so markdown output can be dropped in whole. The measure is 76ch and the wrapper sets it - never size the paragraphs.

  • List markers take the accent
  • inline code sits on bg-raised in accent-secondary
  • Links are underlined in the accent at a 3px offset
Quotes are a hairline and quieter text - no oversized quote marks, no italics.
